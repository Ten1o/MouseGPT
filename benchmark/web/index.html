Research protocol

  1. Verify evidence. Inspect the clean frame and available kinematics.
  2. Reuse expert evidence. Existing judgments guide drafts and review; model descriptions remain suggestions until verified.
  3. Adjudicate & approve. Keep atomic facts, acceptable uncertainty and a reviewer trail.
  4. Compare controlled inputs. Preserve image hash, prompt, settings and model version. Report historical runs separately.

Still frames support posture descriptions. Duration, direction and movement require supporting evidence.

Complete a blinded calibration template

Download the template above. Keep every record ID, binding, hash and context unchanged; edit only the four fields below within each record. Inspect the image, prompt and candidate independently. Set split to development or heldout explicitly, keeping each recording in one split. The import recovers the hidden judge verdict from its saved binding.

"human_label": "supported",
"human_verified": true,
"verified_by": "Human reviewer",
"split": "development"

Claim labels: supported, contradicted or unverifiable. Dimension labels: a score from 0 to 1 using the selected rubric. Do not replace the full template with this four-field example.
